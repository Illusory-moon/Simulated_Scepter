## 1. 问题定义

在差分宇宙中，地图由节点图 $G = (V, E)$ 表示（DAG，仅向右有向边），其中部分节点标记为"可传染"（青绿色节点，可被初始随机感染选中）。目标在三张首尾相连的地图上最大化最终倒计时，且每个位面需满足累计阈值要求。

### 1.1 核心机制

- **移动消耗**：走到非传染节点 $-3$，走到传染节点 $+1$
- **列销毁**：移动到节点 $j$ 后，所有 $x \leq x_j$ 的列被销毁，**包括节点 $j$ 自身**。销毁列上的节点不再可用（不再参与效果结算和后续移动）。
- **随机效果**：每步先结算效果，再择路行走，最后销毁目标列（全部效果统一为此顺序）
- **效果决策**（ex-post）：先看到随机效果 $e$，再决定 keep / cheat / reroll
- **资源**：作弊次数 $C$（自选效果）、重投次数 $R$（重新随机），全程跨地图共享

### 1.2 位面累计阈值

进入第一位面时初始倒计时为 **15**。每位面结束时需满足累计倒计时下限：

| 位面 | 累计阈值 | 净需增量 | 说明 |
|------|---------|---------|------|
| 第一位面 | ≥ 15 | ≥ 0 | 初始 15，不亏即可达标 |
| 第二位面 | ≥ 75 | ≥ 60 | 含第一位面积累 |
| 第三位面 | ≥ 80 | ≥ 5 | 含前两位面积累 |

跨地图资源分配需满足每位面的累计约束，否则该分配不可行。

## 2. 精确动态规划

### 2.1 状态空间

cd 满足**线性可加性**：$V(node, mask, cd, c, r) = cd + W(node, mask, c, r)$

因此 DP 只需维护 4 维状态（无需 cd），精确求解可行：

$$s = (node, \mathbf{I}, c, r)$$

| 变量 | 含义 | 类型 |
|------|------|------|
| $node$ | 当前节点索引 | $\{0, 1, \dots, |V|-1\}$ |
| $\mathbf{I} \subseteq V$ | 传染节点集合（位掩码） | $\{0,1\}^{|V|}$ |
| $c \in \{0,\dots,C\}$ | 剩余作弊次数 | $\mathbb{N}$ |
| $r \in \{0,\dots,R\}$ | 剩余重投次数 | $\mathbb{N}$ |

### 2.2 效果定义

全部等概率 $1/6$：

| 编号 | 名称 | 效果 | 随机性 |
|------|------|------|--------|
| 1 | 扩散 | 每个传染节点独立感染**一个**随机邻居（每源选一，笛卡尔积） | 随机 |
| 2 | 增幅 | $d \mathrel{+}= \|\mathbf{I}_{active}\|$（销毁列上的不计入） | 确定 |
| 3 | 邻接 | 感染**目标位置（下一步节点）**的所有相邻节点 | 确定 |
| 4 | 自选 | 手动选择一个未传染节点感染（玩家选择最优） | 玩家选择 |
| 5 | 随机感染 | 随机感染一个未传染节点（均匀随机） | 随机 |
| 6 | 无事发生 | 无效果 | 确定 |

### 2.3 Ex-post 优化

关键：玩家先看到随机效果 $e$，再决定动作。对每个 $e \in \{1,\dots,6\}$：

$$W(node, \mathbf{I}, c, r) = \frac{1}{6} \sum_{e=1}^{6} \max\begin{cases}
\max_{j \in \text{succ}(node)} V_{\text{after}}(node, \mathbf{I}, e, c, r, j) & \text{keep} \\
\max_{k \in \{1..6\}} \max_{j} V_{\text{after}}(node, \mathbf{I}, k, c-1, r, j) & \text{cheat}(k), c > 0 \\
\frac{1}{6} \sum_{e'} \max_{j} V_{\text{after}}(node, \mathbf{I}, e', c, r-1, j) & \text{reroll}, r > 0
\end{cases}$$

其中 $V_{\text{after}}$ 为应用效果后的期望值（含移动和列销毁）。

若 ex-ante（先决定动作再看效果），期望值显著偏低（约一半），因此采用 ex-post 建模。

### 2.4 状态转移

每步统一顺序：**先结算效果 → 再择路行走 → 最后销毁目标列**。

**Step 1 — 效果结算**：根据效果 $e$ 更新传染掩码 $\mathbf{I}' = f_e(\mathbf{I}, node)$ 和倒计时增量 $d' = g_e(\mathbf{I})$。非增幅效果仅改变掩码（$g_e = 0$），增幅统计当前活跃传染节点数。

**Step 2 — 移动**：选择目标节点 $j$，更新倒计时（在列销毁前判定 $j$ 的感染状态）：

$$d'' = d' + \begin{cases} +1 & \text{if } j \in \mathbf{I}' \;\text{(pre-destruction)} \\ -3 & \text{otherwise} \end{cases}$$

**Step 3 — 列销毁**：设 $col(j)$ 为节点 $j$ 所在列索引（cx 容差 30px 聚簇），销毁所有 $col \leq col(j)$ 的列，**含 $j$ 自身**：

$$\mathbf{I}'' = \{v \in \mathbf{I}' \mid col(v) > col(j)\}$$

关键细节：移动判定 ($\pm 1$ vs $-3$) 使用 Step 2 **销毁前**的 $\mathbf{I}'$，因 $j$ 在 Step 3 即随列销毁，无法从 $\mathbf{I}''$ 中检测。

## 3. 算法实现

### 3.1 BFS 状态枚举

从初始状态 $(start, \mathbf{I}_0)$ 出发，BFS 枚举所有可达的 $(node, \mathbf{I})$ 组合。转移包括所有效果的所有可能结果（扩散含笛卡尔积采样），状态数通常远小于 $2^{|V|}$（受列销毁和有限步数约束）。

大图（$>18$ 节点）自动限制：每节点最多 100 个掩码、总状态 ≤ 5000、扩散采样 ≤ 10。

### 3.2 反向 DP

在拓扑排序的逆序上对每个 $(node, \mathbf{I}, c, r)$ 计算 $W$ 值，查表获得未来状态值。

复杂度：$O(|\text{states}| \cdot |\text{effects}| \cdot |\text{next\_nodes}|)$。

### 3.3 三地图资源分配（含位面阈值约束）

反向归纳 DP，带累计阈值可行性剪枝：

$$best_W[k](c, r, d_k) = \max_{\substack{c_k \leq c \\ r_k \leq r}} \left[ W_k(c_k, r_k) + best_W[k+1](c - c_k, r - r_k, d_k + W_k(c_k, r_k)) \right]$$

约束：$d_k + W_k(c_k, r_k) \geq threshold_k$（不满足则为不可行）。

其中 $d_k$ 为进入位面 $k$ 时的累计倒计时，$threshold_k$ 为该位面要求的下限（15 / 75 / 80）。

复杂度 $O(n \cdot C^2 \cdot R^2)$，对 $C=2, R=3$ 仅 $O(36)$ 次查表。

## 4. 蒙特卡洛控制（MC 路径+效果联合优化）

### 4.1 设计动机

精确 DP 需枚举状态空间 $|\text{states}| \cdot C \cdot R$，当 $C=25, R=150$ 时资源维度爆炸。此外，三地图联合 DP 若使用实际后续地图的 W 表，相当于"预知未来"——当前地图的决策依赖于尚未到达的地图数据。

**MC 控制方案**：每张地图独立训练策略，不窥探未来地图。同时优化**两个决策维度**：

| 维度 | 说明 |
|------|------|
| 路径选择 | 当前节点有多个后继时，走哪个？（DAG 分支） |
| 效果决策 | keep / cheat(自选效果) / reroll（Ex-post，先看效果再决策） |

### 4.2 状态-动作空间

$$s = (node, \mathbf{I}, c, r, e_{obs})$$

其中 $e_{obs} \in \{1..6\}$ 为已观察到的随机效果（ex-post 建模）。

$$a = (next\_node, d)$$

其中 $next\_node \in \text{succ}(node)$，$d \in \{\text{keep}, \text{cheat}(k), \text{reroll}\}$。

动作空间大小：$|\text{succ}(node)| \times (1 + 6\mathbb{1}_{c>0} + \mathbb{1}_{r>0})$

### 4.3 Q 表结构

$$Q[(s, e_{obs})][(next\_node, d)] = [cd_1, cd_2, \dots, cd_n]$$

每个 $(s, e_{obs}, a)$ 条目存储历史上采用此决策后到达终点的**所有最终 CD 值列表**（最多保留 200 个）。策略选择贪心取平均：

$$\pi(s, e_{obs}) = \arg\max_{a} \frac{1}{|Q[s, e_{obs}][a]|} \sum_{cd \in Q[s, e_{obs}][a]} cd$$

### 4.4 ε-greedy 蒙特卡洛控制

```
对每个 episode:
    state ← initial_state(max_cheat, max_reroll)
    当 state 非终止:
        观察随机效果 e_obs ~ Uniform(1,6)
        以概率 ε 随机探索，概率 (1-ε) 贪心选择
        执行 a = (next_node, d) → 转移到新状态
        记录 (s, e_obs, a) 到 trace
    用最终 CD 回补 trace 中所有 (s, e_obs, a)
```

**关键属性**：
- 不做状态枚举 —— 状态由 rollout 自然发现
- 不做模型假设 —— 纯采样学习
- 资源自然消耗 —— 训练时从上限出发，rollout 中自然耗尽，覆盖所有中间资源水平

### 4.5 W 表估计（单图独立）

对每张地图独立跑 MC 训练，然后用已学策略在各 $(c, r)$ 采样点做纯贪心评估：

$$W_k(c, r) = \mathbb{E}_{\text{MC rollout}}[\text{final\_cd} \mid \text{start\_map}_k, \text{resources}=(c, r)]$$

采样策略：密集低值 + 稀疏高值（W 在 $c \approx 5$ 后趋于饱和），双线性插值填充全网格。

### 4.6 三地图联合分配

各图 W 表**独立**估计后（不互窥），用反向归纳做资源分配（同 §3.3）：

$$best_W[k](c, r) = \max_{c_k \leq c, r_k \leq r} \left[ W_k(c_k, r_k) + best_W[k+1](c - c_k, r - r_k) \right]$$

联合 DP 仅做资源分配算术，不接触地图内部结构，因此**不构成预知未来**。

## 5. 模拟验证

使用 $n=2000$ 次蒙特卡洛模拟验证 DP 期望值，每次采样随机效果并根据 ex-post 策略选择最优动作。支持多进程并行（最多 8 workers）。

MC 控制额外提供纯贪心评估（ε=0），直接使用训练好的 Q 表运行 rollout 得到最终 CD 分布。

最优极限 DP（取 max 而非期望）给出理论最大值，用于评估理想情况下的上限。
